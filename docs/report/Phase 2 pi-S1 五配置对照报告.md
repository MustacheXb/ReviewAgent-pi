## 1. 概述与一句话结论

**无红旗，且有两个超预期观察**：pi 内核在 DSH 同案同协议上产出同构可比数据——(1) **C（全仓注入）不塌缩**（judge recall 0.4709 vs dsh-s1 0.0000，DSH 全量也仅 0.1341），DSH 线"全仓注入边际收益为负"的结论被证明是内核条件性的；(2) **E 成为 pi 侧 recall/F1 双冠**（0.6190 / 0.5062），token 只及 dsh-s1 E 的一半。代价是缓存命中全线低 8–36pp（纯成本面）。A（零工具）三列几乎重合，是"内核不是变量"的理想锚点。

## 2. 复算路径（无手抽数字声明）

全部数字由脚本从判定文件机器提取（非手工摘录）：

- **pi-s1 列**：`runs/phase2-pi-s1/judge/vul4j/{VUL4J-29,30,33}/{A..E}/rep-{1..3}.json` × 45——每单元取 `judgePrf.{recall,precision,f1}`、`judgeEfficiency.{rie,carc}`、`tokens.{totalTokens,cacheHitRate}`、`toolCalls`、`rounds`，按配置对 9 单元求均值。

- **DSH 全量参照列**：DSH 报告 §5.1 原值（main 侧 90 单元/配置），用于区分子集偏移与内核效应。

## 4. 读法（对齐 DSH 报告 §5.1 的"谁是冠/方向性/增量"叙事）

**A 是 RIE 冠（三列重合，内核无关性的正面证据）**：pi 0.0222 ≈ dsh-s1 0.0230 ≈ DSH 全量 0.0242；recall（0.529 / 0.492 / 0.501）与 token（21.9k / 19.0k / 22.6k）同样重合。零上下文时模型直觉主导、内核不是变量——A 侧同构性增强了对 C/E 侧差异的归因信心（差异确实来自内核而非协议漂移）。pi 的代价在缓存（hit 0.0726 vs 0.4600；CaRC 21.0k vs 14.3k），纯成本面。

**B 的精度冠在 pi 侧不成立**：dsh-s1 的 B 仍是其 precision 冠（0.5714），与 DSH 全量"B 精度与 F1 冠"同构；pi 侧 precision 冠是 A（0.6111）而非 B（0.4815），B 相对 A 是 recall −25% / precision −21% 的双向劣化——预取管线在 pi 侧这 3 案上是纯噪声。dsh-s1 的 B 有 2/9 零 finding，pi 恒 9/9 产出。

**C 不塌缩——与 DSH 线最重要的形态分歧**（DSH 报告 §5.4"C 实证全线垫底"的 pi 版反转）：

| C 塌缩表征（DSH 报告 §5.4） | DSH 全量 | dsh-s1 | **pi-s1** |
|---|---|---|---|
| judge recall | 0.1341（A 的 27%） | 0.0000 | **0.4709（A 的 89%）** |
| 零 finding 率 | 77% (69/90) | 100% (9/9) | **0% (0/9)** |
| token/单元 | 706.5k | 622.1k | **307.1k** |
| rounds | 3.3 | 2.89 | **1.00** |

DSH 侧"全仓注入把模型淹没：上下文重组成主要噪声源"的机制叙事在 pi 侧同样协议同样案上不成立——pi 的六阶段一轮直驱（rounds 1.00）让全仓注入真正可用，token 只有 DSH 一半。**"全仓注入的边际信息收益为负"是 DSH 内核条件下的结论，不能内核无关地外推**——这是本仓立项问题（"架构有效还是内核有效"）的第一次实证接触。

**D 两侧同为低谷（方向同构，幅度不可比）**：pi 0.1958 与 dsh-s1 0.0847 各为其五配置最低，两侧 D 都跑输各自 A。沿用 DSH 报告 §5.5 呈现纪律：低谷方向跨侧稳定可引用，幅度因循环结构不同（pi rounds 1.11 vs DSH 1.44 / 全量 2.32）不作精确对照。失败形态不同：pi 满产出低命中（9/9 非空，precision 0.3333），DSH 少产出（4/9 非空）。

**E−D（账本增量）方向案集敏感，S1 无权裁定**：DSH 全量的"方向性为负"（0.2355 < 0.2916，三侧一致）在 dsh-s1 子集上本来就不复现（0.3069 > 0.0847，正）；pi-s1 上 E−D = +0.42（0.6190 vs 0.1958，强正）。三个口径三个方向——E vs D 增量方向对案集极端敏感，标记为 **#17 重点验证项**。可以说的是：pi 的 E 是其五配置 recall/F1 双冠，86.1k token 只及 dsh-s1 E 的 47%、DSH 全量 E 的 42%。

**产出密度是全线差异的底层**：pi 45/45 单元有 findings（零 finding 率 0%）vs dsh-s1 25/45（44%，与 DSH 全量 42% 同水平）——C/D/E 的非空计数（9/9 vs 0/9、4/9）是同一现象的配置面投影。

## 5. 判级面（对应 DSH 报告 §3.3"锚塌缩"）

- **dsh-s1 的锚塌缩比 DSH 全量更极端**：全量 anchor C = 0.1341（弱但非零），s1 子集 0.0000——判级 recall 门（不低于 anchor 比例）对零锚全放行，s1 判级只剩 token 门（当年 s1 的 B 配置"A 级"实为 token 门产物）。
- **pi-s1 的 anchor 有效**（0.4709）：E 对锚持平 recall + 27% token 判 B；A/B/D 判 BELOW_B 是对真实锚的差距。pi 侧判级表首次在"锚活着"的条件下运行。

## 6. 机制核查（结论的证据底座，均为实测）

1. **六阶段是共享协议，pi 平移正确**：两侧 A 配置同为 6 请求/单元（Change Understanding → Risk Classification → Context Decision → Context Retrieval → Deep Reasoning → Evidence Verification），消息数同为 3→5→7→9→11→13 递增（append-only 会话）。C/D/E 请求数不同（pi C/D/E = 10/18/9 vs DSH 15/15/34）——工具配置的请求次数由 agent 行为驱动，属 §5.2 Tier 2 预定的"语义一致而非字节一致"内核效应面。
2. **记账口径一致，对照公平性成立**：VUL4J-29/A/rep-1 冷单元总输入 pi 12,216 vs DSH 12,276 token；usage 均为网关返回的累加口径（append-only 会话的重复前缀由网关 prefix cache 折扣记账），两侧可比。
3. **跨 rep 字节稳定**：pi A 配置 rep-1/2/3 首请求 wireBody 逐字节相同（6,703 字节）——pi 的确定性组装纪律生效；A 的缓存命中低不是请求不稳定所致，是 pi-ai 序列化方言在火山网关上的前缀命中问题（见 §7 R1）。
4. **per-case 互补性证明案子翻转效应**：A 配置 rule recall——VUL4J-30 上 pi 0% / DSH 50%，VUL4J-33 上 pi 33.3% / DSH 0%。零上下文下的命中是案子偏好的随机散射；n=9 的任何单格都可被一个案子翻转。
5. **dedup 两侧同零**：E 配置 Context Ledger 去重 pi 0/97 calls、DSH 0/133 calls——3 案工具调用序列无重复模式，共享的案集特征而非 pi 实现缺陷。
