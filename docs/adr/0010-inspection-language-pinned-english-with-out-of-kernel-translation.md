# 检视输出语言恒英文：呈现语言经核外翻译投影，语言从实验自变量降级为呈现配置

两个真实诉求推动了本决策（#13，生产化四必做之二）：落地侧要把 ReviewAgent 接入企业内部代码托管平台，检视结论要呈现给中文母语工程师（自然语言字段需要中文呈现档）；实验侧要与 DSH 兄弟仓在同一评测集与冻结判定链上做内核无关性对照，语言若成为检视行为的参数，请求字节、前缀缓存、golden bytes 与 S 级结论有效域全部需要重新验证（票面预设的 30 案语言抽样质量验证 ~3.8M token 即该路线的准入成本）。2026-10-19 决策评论拍板：放弃票面预设的内核内 en/zh 双语切换，走「英文产出 + 核外翻译投影」。本 ADR 为 pi 线自立决策（本仓 ADR 序列 0010）——DSH 兄弟仓的语言决策是其线内决策（DSH 线 ADR-0010），本 ADR 非其导入（跨仓限定语纪律：裸 ADR 编号一律指本仓序列）。

## 决策

- **检视输出恒英文（测量面冻结）**：Zone A 提示词、请求字节、golden bytes、S 级结论有效域全部不动——检视链整体留在已验证英文域，质量锚定零迁移（已验证的检视质量结论直接对翻译源生效）。
- **呈现语言经核外翻译投影**：中文呈现是消费端关注点，按 CONTEXT.md 核内/核外边界属核外工具链——root `src/presentation/translate-projection.ts`（纯依赖注入、零 pi import）：注入翻译引擎只翻自然语言字段（`Finding.title` / `Finding.description` / 审计工具摘要 `ToolCallRecord.resultSummary`），结构化字段（id / severity P0–P3 代码 / category / file / line / evidence[] 代码摘录 / rule / confidence / 工具名与参数 JSON）字节原样直通（单测逐字段 === 锁定）。
- **en/zh 可切换的落点在呈现面**：`language: "en"` = 恒等直通（零引擎调用——英文呈现档就是源文档本身）；`"zh"` = 引擎翻译自然语言字段。语言参数化缝在内核与实验 plan 中根本不存在——「plan 锁 en」的实现即「无语言键」（回归断言 `tests/presentation/no-language-in-plan-or-kernel.test.ts`：类型级守卫 + 实例级深键扫描双形态）。
- **留痕形态：投影自带，检视审计零改动**：检视审计恒无语言键（RunRecord schema 冻结不被破坏）；投影文档自带 provenance——呈现语言、术语表版本（`TERMINOLOGY_VERSION` 单源，v1 域词口径取 CONTEXT.md Language 节）、源 finding 关联（源 id ↔ 投影 id 一一对应可回溯）。
- **质量责任移到翻译层**：30 案语言抽样质量验证（~3.8M token）取消；翻译层保真抽检为消费端裁量（轻量）。真引擎（LLM/网关）由消费端装配，内核与投影模块零网络零密钥。
- **NON_ENGLISH 候选拦截门转为源头保障**：从「双语模式需要参数化的口径变更负担」转为「锁定翻译源恒英文」的源头门——检视产物恒英文是翻译投影的输入不变量。
- **语言从实验自变量降级为呈现配置**：与 ADR-0008 被测模型参数化同构的降级——模型 id 该进请求参数（实验 CLI `--model`），语言不该进任何请求或 plan；评测面（plan 锁 en）零漂移。

## Considered Options

- **内核内 en/zh 双语切换（票面预设）** / **英文产出 + 核外翻译投影**——被选后者：双语切换要在 Zone A 提示词引入语言参数 → 请求字节漂移、前缀缓存命中漂移、golden bytes 重录、S 级结论需跨语言重验；翻译投影让语言参数化缝根本不存在，字节面与前缀缓存零漂移。
- **30 案语言抽样质量验证** / **翻译层保真抽检（消费端裁量）**——被选后者：质量锚定零迁移——检视链不动，验证对象从「检视质量」缩小为「翻译保真」，抽样成本与责任都归消费端。
- **检视审计携带语言键** / **投影自带留痕**——被选后者：审计带语言键 = RunRecord schema 演进（冻结破坏）+ 审计文件改动外溢；投影留痕让检视产物与呈现产物各自完整、互不污染。
- **术语硬替换器** / **术语表作引擎参考上下文**——被选后者：硬替换破坏叙事流畅与语法正确；带版本号的术语表（版本进留痕）锚定域词口径，翻译由引擎裁量。
- **翻译进 pi 内核包** / **root `src/presentation/` 核外模块**——被选后者：翻译是呈现关注点，进内核违背核内/核外边界，且引入内核包面变更（测量常量面纪律不允许）。

## Consequences

- 检视审计与 RunRecord schema 零改动；检视产物恒英文成为翻译投影的输入契约（NON_ENGLISH 门为源头保障）。
- 评测面回归断言以「无语言参数化缝」形态落地并保持绿：plan 类型与实例无语言键、内核执行缝 `UnitReviewRequest` 无语言参数；既有字节门全绿即语言零漂移的回归证明。
- root `src/presentation/` 新增核外翻译投影模块（`translate-projection.ts` + `terminology.ts` 单源术语表）与测试（含生产入口 E 形态夹具——#11 P5b 对照报告 eb81397：E 为 pi 内核生产入口选型，验证面含 E）。
- 中文呈现质量 = 翻译引擎质量 × 术语表口径，属消费端责任；企业平台接入时自行装配真引擎并做保真抽检。
- 语言永远不能成为实验自变量——若未来确需跨语言检视质量对照，须新 ADR 显式重开测量面冻结（代价同 Considered Options 第一条）。
- 跨仓纪律重申：本 ADR 裸编号指本仓（pi 线）序列；引用 DSH 兄弟仓决策必须写全限定语（如「DSH 线 ADR-0010」）。
