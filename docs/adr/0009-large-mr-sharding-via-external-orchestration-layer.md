# 超界 MR 处理采用骨架外切分编排层（跳过 v1 护栏，直接 v2）

生产化拍板（2026-09-17）Config B 定型后，验证域（≤10 文件、diff ≤2K 行）之外的真实 MR 是生产流量的一部分：现状对超界输入「预取截断留痕后照跑」，质量从未验证。两条候选路线——v1 domainWarning 护栏（标注照跑，spec 前讨论形态）与 v2 切分（按文件组切分 → 分别检视 → 合并去重）——用户拍板跳过 v1 直接 v2（spec #48）。本 ADR 记录切分实现形态的核心决策：**编排层放在六阶段骨架之外**，内核对分片完全无感知。

## 决策

- **骨架外编排（本 ADR 主决策）**：切分器（纯函数）→ N 分片（同仓同 base 子 diff，每片严格落回验证域内）→ 每片独立走标准 Config B 六阶段管线（零改动）→ 合并层（锚点键去重：同 file + 行号窗口 ±3 起步 + rule/category；首见保留 + provenance + evidence 并集）。六阶段骨架、Zone 字节、Evidence Gate 全部不动——不触发 ADR-0006 的内核形态分叉。
- **编排层是普通库**：不进 DSH 插件树；以注入的「单 MR 运行器」接口为依赖，生产 CLI（DSH 检视运行单元适配）与实验 harness（既有单元运行路径适配）调用同一编排函数——验证即生产路径。
- **分片间串行**：兑现 Zone A / Zone B 跨片前缀缓存（B 的成本模型根基），延迟代价换成本与容量确定性。
- **结果增量全部 optional**：`shards` 元数据节与 Finding 级 `shardIds` provenance 仅在切分发生时出现，由合并层在管线外附加（不进模型输出 Schema）；域内 MR 结果字节与现状完全一致（回归锁定硬门槛）。
- **边界语义**：任一维度超界即切（阈值可配，缺省与验证域同源 10 文件 / 2K 行）；单文件自身超界单片执行 + outOfDomain 标注（不拒绝）；分片数超上限（缺省 20）整单拒绝且与运行失败可区分。
- **验证数据走合成组合**（不走生产回流）：VUL4J 同仓多案例逆补丁重组（锚定 fix commit 最新者快照、干净套用 + 文件级不相交硬校验、真值并集）+ 确定性良性填充撑规模；验收三判据（不丢 / 不重 / 不误并）逐案例对比单独直跑基线，#30 对称 max σ 带判定；控制臂隔离填充效应。

## Considered Options

- **v1 domainWarning 护栏先行 / v2 切分直上**——被选 v2 直上：护栏只是把「质量未知」合法化，切分才兑现质量保障；骨架不动使 v2 工程量可控，v1 的护栏价值被 v2 完全覆盖。
- **内核感知切分（六阶段骨架支持分片上下文）/ 骨架外编排**——被选骨架外：六阶段骨架是 ADR-0006 定义的内核形态，动它即与实验冻结形态分叉，引发对齐验证与结论迁移负担；骨架外让每片都是一次标准域内运行，质量主张直接继承验证域背书。
- **分片间并行 / 串行**——被选串行：并行省延迟但挤掉跨片前缀缓存命中（Zone A / Zone B 跨片字节相同是切分形态独有的缓存红利）；B 的成本有界是生产定型依据，不换。
- **语义级切分（跨文件依赖图）/ 包亲和贪心装箱**——被选贪心：确定性、可复现、实现小；语义切分的必要性等真实生产数据证明。
- **验证数据等生产回流 / 合成组合**——被选合成组合：回流要等上线（鸡生蛋），且首批回流无真值；合成组合真值可控（逆补丁法并集）、三判据可机器判定。
- **合并去重按语义（LLM 二次判重）/ 锚点键（file + 行窗 + rule/category）**——被选锚点键：确定性、零额外 LLM 成本；语义判重引入新的不确定性源，与合并层「可回放审计」的要求冲突。

## Consequences

- **合并层成为新的质量责任点**：超界 MR 的质量主张从「单次运行在验证域内」变为「每片在验证域内 + 合并正确性由三判据验证」。锚点键参数（±3 窗口）是可调杠杆：过松误并、过紧重复，验证跑量化后校准。
- **分片边界可能漏检**：跨片文件的交互问题（两片各见一半）不在任何单片的完整视野内——由三判据的「不丢」量化，不预设零损失；这是切分架构的固有边界，如实写入产品语义。
- **极端 MR 仍被拒绝**：分片数超上限整单拒绝，意味着全仓重构级别的 MR 不在服务范围——产品语义是「拒绝优于静默劣化」。
- **成本模型线性外推**：超界 MR 成本 = N × 域内单元 + 合并开销（纯本地）；每片独立审计与 usage 求和使容量规划可计算。
- **域内路径字节零变化是发布硬门槛**：任何 shards 相关字节渗入域内结果即破坏回归锁定——与 ADR-0008 的「缺省路径字节不变」同一纪律。
- 未来若出现「跨片上下文补取」类需求（分片边界漏检的补救），将触碰骨架——须新 ADR，不在本决策范围内。
