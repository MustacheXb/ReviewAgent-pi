# 输出语言配置化：Zone A 按语言分序列与语言门参数化

生产目标团队是中文环境，findings 需要中文输出；而 en 输出路径是全部既有实验结论（Phase 2 三侧 S 级）的锚定形态。两层现状把输出锁在英文：Zone A 系统提示词的输出语言指令，与 Evidence Gate 的 NON_ENGLISH 门（CJK 正则拒绝中文 findings）。改造的约束是**前缀缓存按请求头部字节精确匹配**——Zone A 任何逐请求的字节变化都会摧毁 B 配置的缓存命中（生产定型依据）。spec #49 落地，本 ADR 记录语言切换的架构决策（ADR-0010）。

## 决策

- **输出语言是产品配置**（`outputLanguage: "en" | "zh"`，缺省 en；生产部署显式 zh）：只切换 Finding 的自然语言字段（title / description / evidence 连接文本）；代码摘录、文件路径、标识符、枚举值与字段名不随语言变化。
- **Zone A 按语言分序列（本 ADR 主决策）**：提示词主体英文不动，仅 Output language 节按语言渲染——但不是「一个会变的提示词」，而是**每语言一条冻结字节序列**：en 序列与现状逐字节相同（既有结论零迁移），zh 序列是新增的一条冻结前缀。同一部署固定一个语言时，序列内字节恒定，前缀缓存命中行为与 en 部署对称。语言节指令本身仍以英文书写（英文指令 + 中文输出是模型遵循稳定的组合），内容指定目标语言与「代码摘录 / 路径 / 标识符 / 枚举不翻译」约束。
- **语言门对称参数化**：Evidence Gate 的语言检查跟随 outputLanguage——en 模式拒绝自然语言字段含 CJK（现状不变）；zh 模式要求 title / description 至少其一含 CJK（缺失即语言违规走既有拦截链）。检查的字段面不变，只换语言判据——zh 模式下语言纪律同样有执行器，不静默混语。
- **字节锁按语言参数化**：zone-a-parity（根包与 DSH 双副本 1:1）与 golden bytes 期望值扩为每语言一条——en 期望原样（回归锁），zh 期望新增冻结；任何一字节漂移即红灯。
- **zh 质量主张独立成立**：输出语言影响模型行为，S 级结论不自动迁移到 zh——上线前 30 案 × Config B × 1 rep 抽样验证；judge 提示词逐字节不动（保持与 en 基线可比，语义匹配判据语言中立），全量前 5 案人工 sanity check。
- **manifest 按语言分口径**：运行记录携带 outputLanguage，指标不跨语言混比。

## Considered Options

- **整篇提示词翻译成中文 / 仅语言节参数化**——被选后者：全篇翻译等于造了一个全新提示词，行为变化面大且不可解释；只动一节使 zh 验证结果的差异只能归因于语言切换本身。
- **语言指令逐请求动态拼装 / 每语言冻结序列**——被选冻结：前缀缓存按字节精确匹配，动态拼装使每次请求 Zone A 字节不同、缓存全 miss；分序列保住 B 的成本根基。
- **zh 模式关闭语言门 / 对称参数化（要求 CJK）**——被选对称：无门则混语输出静默通过；对称门保持「语言纪律有执行器」的既有语义，en / zh 同构。
- **换语言后直接沿用 S 级结论 / 抽样验证**——被选验证：S 级锚定的是 en 字节形态下的行为；语言是行为变量，验证后主张才成立。
- **judge 提示词加中文适配 / 逐字节不动**——被选不动：动 judge 破坏与 Phase 2 en 基线的可比性（差异无法归因）；judge 语义匹配本身语言中立；sanity check 兜底，异常再议并显式标注基线破坏。

## Consequences

- **新增语言 = 一条新冻结序列 + 字节锁期望 + 一次抽样验证**：成本可预算，不触及其它语言序列——语言扩展是画像式加法而非乘法。
- **en / zh 双序列并存**：跨语言指标不可直接混比（manifest 分口径）；生产 zh 与实验 en 的质量主张各自独立成立。
- **en 路径零迁移负担**：字节不变是发布硬门槛，与 ADR-0008「缺省路径字节不变」同一纪律——任何 en 字节漂移即回归红灯。
- **zh 质量若显著劣化，杠杆在语言节措辞**（冻结序列内容可换、换后重新冻结并重验证）而非架构。
- 语言门 zh 侧「至少其一含 CJK」是弱判据（防混语下限，不保证纯中文）——接受：强判据（如英文词占比阈值）误伤代码术语引用，得不偿失。
