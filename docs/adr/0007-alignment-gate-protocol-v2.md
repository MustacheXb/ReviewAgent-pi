# 指标对齐门协议 v2：对称 max σ 带、最小样本护栏与单元配对符号检验

#30 噪声底校准把 #29 的出带归因为「跨日部署漂移 + 协议固有非确定性」并留下五条门协议修订建议；本 ADR 把它们落成管线代码（票 #31）：① 单元级 (config × metric) 格判定改用**对称 max σ 带**——带宽取两侧样本 σ 的较大者、中心为基线均值，方向无关（|Δmean| ≤ maxσ 在两侧对称成立），替代 #29 的单侧基线带（带取自哪侧结论就变）；② **最小样本护栏**——任一侧 n < 3 的格标记 `INSUFFICIENT_SAMPLE` 不判定（不 FAIL），把 #30 指认的统计无效格（基线 n=2）显式挡在判定面外；③ 噪声对照在场时以**单元配对符号检验**（精确二项，α=0.05）为主判据——按单元键跨三侧配对、平局剔除计数、仅显著更差方向 FAIL，配对 PASS 的指标其带外格不触发 FAIL（NOT_TESTED / 噪声缺席时回落格判定），替代「池化均值落带」这一对样本量不敏感的口径；④ 判定格 **样本量建议**（judged n < 15）与**时点配对预警**（两侧执行窗间隔 > 48h）进 advisory 面；⑤ #29 遗留单侧带**并列报告**不删除——协议变更可见性 + 历史回放锚定。门以纯函数模块（metrics 层）+ RunStore 加载器（experiment 层）+ 薄 CLI（`pnpm alignment-gate`，退出码 PASS/INCONCLUSIVE→0、FAIL→1、用法/加载错误→2）三层落位，纯离线零网络。

## Considered Options

- 带口径：**#29 单侧基线带（保留为遗留列）** / 对称 max σ 带——被选 / 合并 σ（√(σb²+σc²)）。#30 实证同一对数据带取自哪侧结论就变（DSH-vs-POC1 与反向对照 OUT 格不同），单侧带方向歧义；max σ 带方向无关且不放大自由度（合并 σ 隐含独立样本 t 形态，n=2 格会给假窄带）。遗留列并列而非删除：#29 报告的发布数字需要可复算锚点。
- 护栏位置：**fail fast（整体拒绝跑门）** / 标记不判定——被选。n=2 格的失败是检验力问题不是对齐失败（#30 结论），fail fast 会让「恰好缺一 rep」的整场实验不可跑；标记 `INSUFFICIENT_SAMPLE` 保留其余格的判定力，verdict 落 INCONCLUSIVE 由整体判定逻辑吸收。
- 配对判据：**Wilcoxon 符号秩** / 精确二项符号检验——被选。符号检验只消费「更差/更好/平」三元信息，对指标量纲无关（recall 离散格与 token 连续格同一代码路径）；精确二项在 n≤45 免分布假设。Wilcoxon 消费 |Δ| 秩，对「大幅更差一单元 vs 轻微更差多单元」更敏感，后置为 n 更大时的升级项（Consequences）。
- 模块位置：**单文件 CLI 内联** / metrics 纯函数层 + experiment 加载器 + scripts 薄入口——被选。门协议是判定链的可复述资产（Phase 2 benchmark 验收将引用），纯函数层免 IO 可穷举测试（22 用例覆盖带构造/方向无关/护栏/配对/平局/预警）；加载器独立测试 RunStore→evaluateRun→flatten 的同径性（与实验报告同一指标管线，杜绝门自造第二套口径）；scripts 入口沿 repo「tsc → .tmp-gen → node」脚本先例零行为逻辑。
- 遗留带并列的报告形态：**删除（v2 即真相）** / 并列报告——被选。协议修订若无对照面，「19 IN」与「18/20」之间的差异不可归因；并列让每次门报告同时携带两代口径，读者可见哪些格因协议变化改变判定。

## Consequences

- **比 #30 门 D 更严一格**：门 D（对称带、无护栏）把 C/linePrecision（基线 n=2）判 IN，v2 判 `INSUFFICIENT_SAMPLE`——这是有意为之：#30 的工程判断（无系统偏差证据）依赖「该格统计无效」的人读归因，v2 把这个归因变成代码行为，同类格不再需要人读豁免。
- 符号检验平局剔除与 #30 描述统计的口径差已登记：#30 的 P(|Δdsh|>|Δr2|) 把平局计入分母（recall 11/45=0.24），符号检验剔除（11/24）——两者在「更差计数」上一致（11/6/23/23），结论不漂移但数字不可混引。
- Wilcoxon 后置：当前单元数（45）下符号检验检验力足够（4 指标全 PASS、p ∈ [0.14, 0.62]）；主数据规模（30 case × 5 config × 3 rep = 450 单元）若出现边界 p 再升级，届时与本 ADR 同变更。
- 遗留列随时间退化为纯历史锚：#29/#30 报告数字全部可由本 CLI 复算后（见实现注记），遗留带不再进任何新验收——新实验只引用 v2 判定。
- 门不进 CI：输入是真实网关留痕（runs/ 不入仓），CI 无法持有复算数据；确定性部分（纯模块 + 加载器 + CLI）已由 34 项单测覆盖（22 模块 + 5 加载器 + 7 CLI）。

### 实现注记（#31 落地后补记，2026-09-12）

- **回放锚定（runs/ 本地留痕，不入仓）**：三组真实数据回放全部复现已发布数字——① DSH-vs-r1（噪声 r2）：遗留列 18 IN / 2 OUT 逐格复刻 #29 §3.1（含 C/cacheHitRate 0.9312±0.0142 → 0.8766 与 n=2 的 C/linePrecision）；对称列 19 IN + 1 `INSUFFICIENT_SAMPLE` 复刻 #30 门 D 加护栏；配对面四指标 mean|Δ|（0.1500/0.2854/180727/0.0974 vs 0.1889/0.3281/190456/0.0991）与 worse 计数（11/6/23/23）逐字复刻 #30 §4.1，四指标 p ∈ [0.14, 0.62] 全 PASS。② r2-vs-r1（无噪声）：遗留列恰 1 OUT（E/cacheHitRate Δ−0.0738）复刻 #30 门 A，对称列 19 IN + 1 样本不足。③ 时点面：baseline 窗 [14:13:58Z…18:39:47Z]、DSH 间隔 63.0h / r2 间隔 70.1h，双超 48h 预警——#30 的「跨日部署漂移」归因获得可复算的预警留痕。
- **σ 算术的测试纪律**：n=2 样本 std（n−1 分母）= 偏差 × √2——夹具 [0.5, 0.25] 才给出 #29 发布的 0.3750±0.1768；n=9 精确夹具用 `spreadNine(mean, σ)`（偏差模板 × 归一系数）免手算。发布数字进夹具即锚：协议回退会在测试面变红。
- **平局的诚实呈现**：recall 离散格平局占比高（45 对中 21 平），配对表 worse/better/ties 三元全展示而非只报 p——「平局多到检验不可用」与「显著更差」是两种不同的 INCONCLUSIVE 来源，报告面可区分（validTriplets=0 → `NOT_TESTED`）。
- **配对主判据的前置规则（评审修正后语义）**：「配对检验升主判据」按指标生效——该指标配对 PASS 时其带外格不触发 FAIL（带外 = 检验力问题，advisory「格带外由配对检验否决」可见），NOT_TESTED / 噪声侧缺席时该指标回落格判定；配对 FAIL 恒 FAIL。首版实现保留了带 OUT 的无条件否决权（配对只是加判据），与 #30 修订意图相悖，双轴评审（Spec 轴）指出后修正。同批修正：样本量建议取**最小侧** n（小侧才是 σ 不稳源，取 max 会漏报候选侧 n<15）；时点间隔改**两窗区间距离**（候选窗在基线窗之前的反向时点不再漏报，重叠为 0 不预警）。
- **CLI 退出码契约与共享骨架**：参数解析走 `src/shared/cli-args.ts` 共享骨架（experiment / reference 双 CLI 同款）——`--flag value` 与 `--flag=value` 双取值形式、`--help`、裸 `--`（end-of-options）跳过；`pnpm alignment-gate -- --baseline …` 与不带 `--` 两种调用形态均合法。数值域规则单源：解析层只查「是不是数」，域校验收尾统一经 `validateAlignmentGateOptions`（模块导出，CLI 与 API 共用）。单元键复用 `runUnitKeyString`（contracts/run-unit 稳定键形，与断点续跑/报告分组共用），不再自造第三种键格式。
